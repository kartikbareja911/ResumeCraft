## 🔑 You must do: verify Google Search Console (10 minutes)

The site can't be *submitted* to Google from code — verification requires your
Google account.

1. Open <https://search.google.com/search-console> and sign in.
2. **Add property → URL prefix** → `https://resumecraftco.vercel.app`.
3. Choose **HTML tag** verification. Google gives you a line like:
   `<meta name="google-site-verification" content="abc123..." />`
4. Paste it into `frontend/index.html` right under the comment that says
   `Google Search Console ownership verification`, commit, and let Vercel deploy.
5. Back in Search Console, click **Verify**.
6. Once verified:
   - **Sitemaps →** submit `https://resumecraftco.vercel.app/sitemap.xml`
   - **URL Inspection →** request indexing for `https://resumecraftco.vercel.app/`
   - Repeat the URL Inspection step after each significant content update.

Optional: create a free account on Google Analytics 4 and Bing Webmaster Tools
(Bing lets you import the Google property in one click).

### What to expect

- First crawl/index of a new property typically takes **days to a few weeks**.
- Watch **Performance** (impressions → clicks) and **Core Web Vitals** reports.
- The robots.txt blocklist keeps `/dashboard` and `/editor` out of the index,
  so expect indexed pages: landing, privacy, terms.

## Ongoing ranking habits

1. **Content**: the landing page's H1/FAQ copy already targets "free AI resume
   builder" and "ATS score checker". Add one genuinely useful public page per
   month (e.g. `/blog/how-ats-scoring-works`, `/resume-examples`) — each with a
   unique title/description via `SEO.jsx`, added to `sitemap.xml`.
2. **Core Web Vitals**: after each deploy, run PageSpeed Insights
   (<https://pagespeed.web.dev>) on the live URL. The app ships zero raster
   images and code-split routes, so LCP is driven by the font CSS and the JS
   bundle — keep the critical-font list in `index.html` minimal.
3. **Backlinks**: see `BACKLINK-STRATEGY.md`.
4. **Keep structured data honest**: if you edit the FAQ answers in
   `Landing.jsx`, the `FAQPage` JSON-LD is generated from the same array, so it
   stays in sync automatically. Don't add JSON-LD describing content that isn't
   visible on the page — Google penalizes that.
