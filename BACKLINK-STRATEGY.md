# ResumeCraft Backlink Strategy

Goal: earn links from sites Google already trusts so that
`resumecraftco.vercel.app` gains domain authority for
"free resume builder", "ATS score checker", and related searches.

**Target: 20–30 quality backlinks in the first 90 days.** One link from a
relevant, real site beats 100 directory spam links — never buy links or join
link-exchange schemes (Google penalizes both).

---

## Tier 1 — Launch platforms (week 1–2, highest ROI)

| Platform | Action | Expected link |
|---|---|---|
| **Product Hunt** | Launch as a free tool. Prepare 5 screenshots, a 60-sec demo, and a maker comment. | dofollow, high traffic |
| **Hacker News (Show HN)** | Post "Show HN: I built a free resume builder with real-time ATS scoring" — lead with the ATS engine, it's the differentiator. | dofollow if it sticks |
| **Reddit** | r/resumes, r/jobs, r/EngineeringResumes, r/cscareerquestions — share as a free tool, answer questions first, never just drop links. | nofollow, but referral traffic + brand queries |
| **Indie Hackers / BetaList** | Product page + short build-in-public story. | dofollow |
| **dev.to / Hashnode / Medium** | Write "How ATS parsers actually read your resume (and how I scored mine)" — technical deep-dive, link to the product once. Canonicalize cross-posts. | dofollow |

## Tier 2 — Directories & lists (week 2–6)

- **AlternativeTo** — list under alternatives to Zety, Resume.io, Novoresume (position: free).
- **Free-for.dev, awesome-free-tools, Awesome README lists on GitHub** — submit PRs to curated "free tools" lists.
- **SaaS directories**: G2, Capterra (free listings), Futurepedia, There's An AI For That (AI-tool angle), ToolFinder, AIcyclopedia.
- **College career-center pages**: email 10 university career services and offer the free tool for students — `.edu` links are disproportionately valuable.

## Tier 3 — Content-driven links (month 2–3, compounding)

1. **Free tool as link bait**: the ATS checker itself is the asset. Publish a
   public, no-login page like "ATS resume score benchmark report" once you have
   anonymized usage stats — journalists and career bloggers cite data.
2. **Guest posts** (2–3/month): pitch career blogs, bootcamp blogs, and HR
   newsletters with original angles ("We parsed 500 resumes — here's what ATS
   systems reject"). One contextual link per post.
3. **HARO / Connectively / Qwoted**: respond to journalist queries about job
   hunting and hiring tech. A single quote in a major outlet is worth more than
   everything else on this page.
4. **Open source**: if any of the ATS scoring logic can be extracted into a small
   MIT-licensed npm package or GitHub repo, README links +awesome-list mentions
   add steady dofollow links.

## Tier 4 — Partnerships (ongoing)

- University coding clubs and bootcamps: offer a free "resume review day" using
  the tool; they usually link back.
- Career coaches: free accounts in exchange for a testimonial page link.
- Newsletter sponsors swaps with small career-development newsletters (5–20k subs).

---

## Anchor text guidance

Vary anchors and keep them natural:

- Branded (majority): "ResumeCraft"
- URL: `resumecraftco.vercel.app`
- Partial-match (sparingly): "this free ATS resume checker"
- Never mass-produce exact-match anchors like "free resume builder" — that
  pattern is a manual-penalty signal.

## Do NOT

- Buy links or join "link exchange" Telegram/Discord groups.
- Spam comment sections with URLs.
- Submit to low-quality general web directories (pre-2015 SEO).
- Put the link in AI-generated mass guest posts — Google's spam-brain systems
  target exactly this.

## Track it

- Search Console → Links report (top linked pages, anchor text).
- Free rank tracking: Google Search Console Performance filtered by query
  ("resume builder", "ats checker", "free resume scanner").
